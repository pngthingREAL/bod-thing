## Comandos

### !hola

El bot responde con un saludo al usuario.


### !dado

Genera un número aleatorio del 1 al 6.


### !ayuda

Muestra todos los comandos disponibles.


## Instalación

Primero instala las librerías:

pip install -r requirements.txt


Después crea un archivo llamado:

.env

y coloca:

TOKEN=tu_token


Finalmente ejecuta:

python bot.py
